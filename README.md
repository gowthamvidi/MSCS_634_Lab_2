# MSCS_634_Lab_2

## Purpose
The purpose of this lab was to compare the performance of K-Nearest Neighbors (KNN) and Radius Neighbors (RNN) classifiers using the Wine dataset from Scikit-Learn.

## Methodology
- Loaded and explored the Wine dataset.
- Split the data into training and testing sets.
- Implemented KNN using multiple k values.
- Implemented RNN using multiple radius values.
- Evaluated model accuracy and visualized the results.

## Key Findings
- KNN produced consistent accuracy across different k values.
- RNN performance varied depending on the selected radius.
- Parameter tuning plays an important role in classification performance.

## Conclusion

Both KNN and RNN were able to classify the dataset successfully. KNN was generally easier to configure and provided more stable results, while RNN required careful selection of the radius parameter.
